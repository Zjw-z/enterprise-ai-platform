# 压测、故障演练与备份恢复

## Agent 链路压测

```powershell
python scripts/load_test.py `
  --agent weather-agent `
  --requests 100 `
  --concurrency 10 `
  --api-key your-api-key
```

脚本输出成功率、平均延迟和 P95。正式容量验收应同时采集 `/metrics`，
并覆盖普通对话、工具调用、知识检索和长响应四类场景。

## 故障演练

正常状态：

```powershell
python scripts/fault_probe.py --expect-ready yes
```

在受控测试环境停止 PostgreSQL 或 Milvus 后：

```powershell
python scripts/fault_probe.py --expect-ready no
```

验收标准是 liveness 仍为 200，而 readiness 为 503。恢复依赖后 readiness
必须自动回到 200。不要在未准备回滚方案的生产环境直接停止依赖。

## 备份

```powershell
.\scripts\backup.ps1 `
  -Destination D:\backup\eap-20260728 `
  -DatabaseUrl "postgresql://user:password@host:5432/enterprise_ai"
```

脚本使用 `pg_dump` 创建 PostgreSQL 自包含备份，并在安装 MinIO Client (`mc`)
时镜像对象存储。配置快照不应包含明文 Secret。

## 恢复

恢复会修改持久化数据，因此脚本要求显式确认：

```powershell
.\scripts\restore.ps1 `
  -Source D:\backup\eap-20260728 `
  -DatabaseUrl "postgresql://user:password@host:5432/enterprise_ai" `
  -ConfirmRestore
```

恢复前应停止 API 和 Worker，恢复后依次执行数据库迁移、readiness 检查、
知识检索抽样验证和 Agent 回归评测。建议至少每季度完成一次完整恢复演练。
